Project Title
Education – Student Attendance Monitoring System
Project Description
This proposed system helps teachers record and monitor student attendance. It collects student details, records whether each student is present or absent, counts the totals, and displays an attendance summary.
Problem Statement
Recording attendance manually can take time and may lead to counting mistakes. This project proposes a simple system to make attendance recording easier.
Objectives
•	Collect students' identification numbers and names.
•	Record whether each student is present or absent.
•	Count students present and absent.
•	Display a daily attendance summary.
Main Features
•	Enter the number of students.
•	Enter each student's ID and name.
•	Record attendance status.
•	Calculate present and absent totals.
•	Display the attendance report.
Programming Concepts
Algorithms, pseudocode, flowcharts, input, processing, output, decisions, loops, modules and functions.
How the System Works
The teacher enters the number of students. The system collects each student's ID, name, and attendance status. If the student is present, the present counter increases by one. Otherwise, the absent counter increases by one. This repeats until all students have been recorded. The system then displays the summary.
Project Status
This is a proposed logical design. Programming, testing, and secure data storage may be needed before real school use.
